# Eason 刘雨生 · 个人网站

网站：https://liuyusheng-ai.github.io/

静态 HTML、CSS 与原生 JavaScript，无需构建或安装依赖。GitHub Pages 从 `main` 分支根目录发布，保留 `.nojekyll`。

## 文件结构

| 文件 | 作用 |
| --- | --- |
| `index.html` | 全部页面内容（含案例完整技术细节），无 JS 时也可完整阅读 |
| `styles.css` | 唯一样式表：设计变量 → 基础 → 组件 → 各章节 → 响应式 → 打印 |
| `main.js` | 导航高亮、阅读进度、深链展开、案例筛选、沟通示例、Agent 实验室、联系主题 |
| `constellation.js` | 首页知识星系（辅助探索入口）与档案弹窗 |
| `favicon.svg` | 站点图标 |
| `resume.docx` | 完整简历下载 |

修改颜色、字号、间距时，优先改 `styles.css` 顶部的 `:root` 变量。

## 页面结构

首页 → 01 完整介绍 → 02 项目案例 → 03 教育与实习经历 → 延伸阅读（Agent 实验室，默认折叠）→ 04 联系。

- 首页提供“完整了解我”和“查看项目案例”两个主入口，下方是经历概览数字。
- 完整介绍：方向、能力、合作方式，四步工作方法，以及“合作从提问开始”的沟通示例。
- 项目案例：每个案例直接展示系统链路、问题、个人工作、结果与关键指标；完整技术细节按需展开，评测口径写在案例底部。
- 深链：`#case-rag`、`#case-research`、`#case-sql` 定位到案例；`#case-rag-detail` 等会直接展开细节；`#playground`、`#system` 会自动展开实验室。
- 知识星系约每 3 秒轮换主题；鼠标悬停时暂停，拖动、方向键或选主题切换为手动浏览，可随时“继续导览”。减少动态效果偏好下为静态。

## 内容与互动边界

项目和经历依据个人简历整理。研究 Agent 与 Text-to-SQL 属于开源示例上的个人二次开发。确定性离线评测、真实模型及联网结果分开说明。

Agent Playground 与系统设计为本地预设演示，不调用模型、数据库或采集用户输入。选择联系主题只预填邮件标题，不自动发送邮件。

网站包含经本人确认可公开的联系方式和完整简历。

## 设计方向

暖白底、墨绿与低饱和古铜点缀；英文字标使用 Instrument Serif（非阻塞加载，失败时回退系统衬线），中文全部使用系统字体。正文 16.5–19px，标签不小于 13px。动效只保留滚动渐显、星系与按钮反馈，均遵守“减少动态效果”设置。
