# Eason 刘雨生 · 个人网站

网站：https://liuyusheng-ai.github.io/

静态 HTML、CSS 与原生 JavaScript，无需构建或安装依赖。GitHub Pages 从 `main` 分支根目录发布，保留 `.nojekyll`。

## 文件结构

| 文件 | 作用 |
| --- | --- |
| `index.html` | 全部页面内容（含案例完整技术细节），无 JS 时也可完整阅读 |
| `styles.css` | 唯一样式表：字体 → 设计变量（深色默认 + 浅色）→ 基础 → 组件 → 各章节 → 响应式 → 打印 |
| `main.js` | 顶部为文案数据（沟通示例、实验室轨迹、联系主题），其后是各交互模块，每个模块独立启动 |
| `fonts/` | 自带的英文字体子集（Instrument Serif、JetBrains Mono）及 SIL OFL 许可 |
| `og-image.jpg` | 1200×630 分享卡片 |
| `404.html` | 同风格的找不到页面（资源路径用根路径，任何层级都能正确加载） |
| `favicon.ico`、`favicon.svg`、`apple-touch-icon.png` | 浏览器标签、旧浏览器与 iOS 主屏图标 |
| `robots.txt`、`sitemap.xml` | 搜索引擎配置 |
| `resume.docx` | 完整简历下载 |
| `scripts/check.py` | 发布前自检 |
| `.editorconfig`、`.gitignore` | 编辑器约定（UTF-8、LF、两格缩进）与忽略文件 |

修改颜色、字号时，优先改 `styles.css` 顶部的 `:root`（深色）与 `:root[data-theme="light"]`（浅色）变量。改动页面文案时，`index.html` 与 `main.js` 顶部的数据需与简历保持一致；邮箱只写在页面的 `mailto:` 链接里，脚本从那里读取。

## 发布流程

```bash
python3 scripts/check.py
```

1. **改了 `styles.css` 或 `main.js`**：把 `index.html` 和 `404.html` 里的 `?v=` 改成新值（格式 `年月日.序号`，如 `20261108.2`）。值不变时，老访客的浏览器会继续用缓存里的旧文件。
2. **改了 `<head>` 里的内联主题脚本**：两页必须保持一致，然后运行 `python3 scripts/check.py --fix-csp` 自动更新内容安全策略（CSP）里的哈希；否则这段脚本会被浏览器拦截。
3. **运行自检**，全部通过后再推送。自检内容：重复 id、坏锚点、缺失资源（HTML、CSS 与站内绝对链接如分享图）、脚本引用的 id、JS 语法、两页缓存版本号一致、内联脚本与 CSP 哈希匹配、没有会被 CSP 拦截的内联样式或事件属性，以及两套主题所有文字颜色达到 WCAG AA（≥4.5:1）。有问题时以非零状态退出。
4. 更新 `sitemap.xml` 的 `lastmod`。

## 设计：有据可循

- **布局**：桌面端左侧为固定的身份栏（姓名、定位、主张、章节导航、简历与联系），右侧滚动阅读；窄屏变为顶部栏 + 单栏，横屏手机上顶部栏随页面滚走。
- **视觉**：深色墨底、象牙白文字、单一香槟色强调。浅色模式（暖白、墨绿、古铜）的切换按钮在桌面端左栏底部、窄屏顶部栏右侧，选择会被记住；默认深色是有意的设计选择。
- **字体**：英文名与数字用 Instrument Serif，元数据与执行轨迹用 JetBrains Mono，均为站内自带的拉丁子集（共约 46KB，预加载，不依赖 Google Fonts，国内可正常加载）；中文全部用系统字体，正文 16.5–17.5px。
- **细节**：桌面端光标柔光（只移动合成层，不重绘整屏）、深色主题下悬停时同组其他条目轻微淡出、滚动渐显（只有确认在屏幕外的内容才会先隐藏）；章节高亮用 IntersectionObserver，滚动时不做布局测量；全部遵守“减少动态效果”。
- **屏幕适配**：左栏在矮屏（≤880 / ≤720 / ≤600px 高）分级紧凑，1366×650 等常见笔记本视口完整可见，更矮时左栏自身可滚动；320px 小屏指标改为竖排；锚点落点只由一处 `--anchor-offset` 控制。
- **无障碍**：两套主题文字对比度均 ≥4.5:1；单一 banner 地标；主题按钮朗读“切换到浅色 / 深色模式”；新标签页链接有读屏提示；跳到正文链接把焦点放进正文；Windows 高对比度模式下图标与选中状态仍可辨认。
- **稳健性**：每个交互模块独立启动，一个出错不影响其他；残缺的分享链接（如 `#%E0%A4%A`）不会报错；禁用 JavaScript 时隐藏无法使用的按钮并给出说明；复制邮箱在微信等内置浏览器有兜底方案。
- **安全**：CSP 只允许加载本站资源，内联脚本按哈希放行。

## 页面结构

01 完整介绍 → 02 项目案例 → 03 教育与实习经历 → 04 Agent 实验室 → 05 联系。

- 项目案例直接展示系统链路、问题 / 做法 / 验证、关键指标与技术栈；完整技术细节按需展开，评测口径写在案例底部。
- Agent 实验室是终端风格的本地预设执行轨迹：可选任务与条件（正常 / 无证据 / 工具故障），运行、暂停、继续、单步或重新运行，观察安全退出路径。
- 深链：`#case-rag`、`#case-research`、`#case-sql` 定位到案例；`#case-rag-detail` 等直接展开细节；`#playground` 定位到实验室。章节 id 沿用旧版本（`#approach` = 完整介绍，`#about` = 经历），以免已分享的链接失效。
