# Eason 刘雨生 · Personal Website

个人网站：https://liuyusheng-ai.github.io/

AI Agent / 大模型应用开发作品集。静态 HTML、CSS 与原生 JavaScript，无需安装依赖。

## 首页个人知识星系

- 点击关于、项目、技能、经历、实验室、联系六个节点，查看摘要并展开简历档案。
- 粒子在球体、聚合体、双螺旋等形态之间变化；支持拖动旋转、暂停与方向键操作。
- 搜索框仅用关键词匹配本站个人档案，不向外部发送输入，也不调用大模型。
- 档案支持直接进入项目详情、实验室与联系区；保留完整简历下载。

## 互动体验

- Agent Playground：行业研究、只读 SQL、安全边界三种预设任务。
- 支持自动运行、暂停、逐步执行和重置，切换场景会取消正在运行的演示。
- 正常、证据不足、工具不可用三种条件；输出明确标记为本地演示，无模型调用、数据库连接或用户输入采集。
- 按知识检索、多智能体、数据分析筛选作品。
- 粒子作品可暂停；滚动出现动效尊重系统减少动态效果设置。
- 选择联系主题可预填邮件标题，不自动发送邮件。

GitHub Pages 从 main 分支根目录发布。保留 .nojekyll。网站包含经用户确认可公开的联系方式与完整简历下载。

## 首页模型漫游与选择

- 模型在可见且无人操作时，每约 3 秒切换主题和粒子形态；输入框获得焦点、离开视口或后台时暂停轮播计时；悬停模型不再中断自动切换。
- 拖动超过 7 像素后进入选择模式，停止自动旋转和轮播；横向拖动约 65 像素切换一个主题。也支持主题按钮、方向键和回车展开档案。
- “继续漫游”恢复自动展示，暂停按钮可手动控制。减少动态效果模式默认暂停，不自动轮播。
- 模型降低粒子对比、减弱连线与面板边框；全页曲面改为青绿色线框、稀疏发光节点和细网格背景，保留文字区域的浅色遮罩。

- 自动导览按关于我 → 联系 → 实验室 → 项目 → 技能 → 经历轮换，显示下一个主题与循环进度条。
- 背景继续沿用参考站“滚动进度同步多层视觉”的方法，线框、节点与曲面共用投影坐标，避免装饰各自运动造成混乱。
