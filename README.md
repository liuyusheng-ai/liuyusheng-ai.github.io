# Eason 刘雨生 · 个人网站

网站：https://liuyusheng-ai.github.io/

静态 HTML、CSS 与原生 JavaScript，无需构建或安装依赖。GitHub Pages 从 `main` 分支根目录发布，保留 `.nojekyll`。

## 文件结构

| 文件 | 作用 |
| --- | --- |
| `index.html` | 全部页面内容（含案例完整技术细节），无 JS 时也可完整阅读 |
| `styles.css` | 唯一样式表：设计变量（深色默认 + 浅色）→ 基础 → 组件 → 各章节 → 响应式 → 打印 |
| `main.js` | 顶部为文案数据（沟通示例、实验室轨迹、联系主题），其后是各交互模块 |
| `fonts/` | 自带的英文字体子集（Instrument Serif、JetBrains Mono）及 SIL OFL 许可 |
| `og-image.jpg` | 1200×630 分享卡片 |
| `404.html` | 同风格的找不到页面（资源路径用根路径，任何层级都能正确加载） |
| `robots.txt`、`sitemap.xml` | 搜索引擎配置 |
| `favicon.svg` | 站点图标 |
| `resume.docx` | 完整简历下载 |
| `scripts/check.py` | 发布前自检 |

修改颜色、字号时，优先改 `styles.css` 顶部的 `:root`（深色）与 `:root[data-theme="light"]`（浅色）变量。改动页面文案时，`index.html` 与 `main.js` 顶部的数据需与简历保持一致。

## 发布前自检

```bash
python3 scripts/check.py
```

检查重复 id、坏锚点、缺失资源（HTML 与 CSS）、脚本引用的 id、JS 语法、两页的缓存版本号是否一致，以及两套主题所有文字颜色是否达到 WCAG AA（≥4.5:1）。有问题时以非零状态退出。

改了 `styles.css` 或 `main.js` 后，同时把 `index.html` 和 `404.html` 里的 `?v=` 版本号改成当天日期，避免访客浏览器用旧缓存。

## 设计：有据可循

- **布局**：桌面端左侧为固定的身份栏（姓名、定位、主张、章节导航、简历与联系），右侧滚动阅读；窄屏变为顶部导航 + 单栏。
- **视觉**：深色墨底、象牙白文字、单一香槟色强调；右下角可切换浅色（暖白、墨绿、古铜），选择会被记住。
- **字体**：英文名与数字用 Instrument Serif，元数据与执行轨迹用 JetBrains Mono，均为站内自带的拉丁子集（共约 46KB，不依赖 Google Fonts，国内可正常加载）；中文全部用系统字体，正文 16.5–17.5px。
- **细节**：桌面端光标柔光（只移动合成层，不重绘整屏）、悬停时同组其他条目淡出、滚动渐显；章节高亮用 IntersectionObserver，滚动时不做布局测量；全部遵守“减少动态效果”。
- **无障碍**：两套主题文字对比度均 ≥4.5:1；主题按钮朗读“切换到浅色 / 深色模式”；跳到正文链接；日期使用 `<time>`。

## 页面结构

01 完整介绍 → 02 项目案例 → 03 教育与实习经历 → 04 Agent 实验室 → 05 联系。

- 项目案例直接展示系统链路、问题 / 做法 / 验证、关键指标与技术栈；完整技术细节按需展开，评测口径写在案例底部。
- Agent 实验室是终端风格的本地预设执行轨迹：可选任务与条件（正常 / 无证据 / 工具故障），运行或单步观察安全退出路径。
- 深链：`#case-rag`、`#case-research`、`#case-sql` 定位到案例；`#case-rag-detail` 等直接展开细节；`#playground` 定位到实验室。
