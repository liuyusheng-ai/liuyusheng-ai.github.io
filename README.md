# Eason 刘雨生 · 个人网站

网站：https://liuyusheng-ai.github.io/

静态 HTML、CSS 与原生 JavaScript，无需构建或安装依赖。GitHub Pages 从 `main` 分支根目录发布，保留 `.nojekyll`。

## 文件结构

| 文件 | 作用 |
| --- | --- |
| `index.html` | 全部页面内容（含案例完整技术细节），无 JS 时也可完整阅读 |
| `styles.css` | 唯一样式表：字体 → 设计变量（深色默认 + 浅色）→ 基础 → 组件 → 各章节 → 响应式 → 打印 |
| `main.js` | 顶部为文案数据（沟通示例、实验室轨迹、联系主题），其后是各交互模块（主题、顶栏、章节高亮、菜单、深链、沟通示例、实验室、联系、链路点亮、滚动渐显），每个模块独立启动 |
| `fonts/` | 自带的英文字体子集（Instrument Serif、JetBrains Mono）及 SIL OFL 许可 |
| `og-image.jpg` | 1200×630 分享卡片 |
| `404.html` | 同风格的找不到页面（资源路径用根路径，任何层级都能正确加载） |
| `favicon.ico`、`favicon.svg`、`apple-touch-icon.png` | 浏览器标签、旧浏览器与 iOS 主屏图标 |
| `robots.txt`、`sitemap.xml` | 搜索引擎配置 |
| `resume.docx` | 完整简历下载 |
| `scripts/check.py` | 发布前自检 |
| `.editorconfig`、`.gitignore` | 编辑器约定（UTF-8、LF、两格缩进）与忽略文件 |

修改颜色、字号时，优先改 `styles.css` 顶部的 `:root`（深色）与 `:root[data-theme="light"]`（浅色）变量。改动页面文案时，`index.html` 与 `main.js` 顶部的数据需与简历保持一致；邮箱只写在页面的 `mailto:` 链接里，脚本从那里读取。

## 发布流程

```bash
python3 scripts/check.py
```

1. **改了 `styles.css` 或 `main.js`**：把 `index.html` 和 `404.html` 里的 `?v=` 改成新值（格式 `年月日.序号`，如 `20261108.2`）。值不变时，老访客的浏览器会继续用缓存里的旧文件。
2. **改了 `<head>` 里的内联主题脚本**：两页必须保持一致，然后运行 `python3 scripts/check.py --fix-csp` 自动更新内容安全策略（CSP）里的哈希；否则这段脚本会被浏览器拦截。
3. **运行自检**，全部通过后再推送。自检内容：重复 id、坏锚点、缺失资源（HTML、CSS 与站内绝对链接如分享图）、脚本引用的 id、JS 语法、两页缓存版本号一致、内联脚本与 CSP 哈希匹配、没有会被 CSP 拦截的内联样式或事件属性，以及两套主题所有文字颜色达到 WCAG AA（≥4.5:1）。有问题时以非零状态退出。
4. 更新 `sitemap.xml` 的 `lastmod`。

## 设计：有据可循（编辑版）

参考了 14 个 Awwwards「Site of the Day」个人作品集：常驻界面只保留一条细顶栏，身份放进会随滚动离开的首屏，作品放大、少而精。

- **常驻界面**：只有一条 56px 顶栏——名字、5 个章节链接（「项目」右上角标出数量）、简历下载、主题切换、「聊聊」。窄屏（<900px）时章节链接与简历收进「菜单」，菜单是原生 `<details>`，禁用 JavaScript 也能打开。顶栏始终是与页面同色的毛玻璃底（禁用 JavaScript 时正文也不会透出），页面滚动后才出现底部分隔线。
- **首屏海报**：主张「把需求聊清楚，让 AI 真正落地。」居中放大，底部是巨型字标 Eason，四角是等宽小字的基本事实（方向、求职状态、学校与成绩、项目与实习数量）。首屏高度留出约 150px，让项目索引的第一行露出来。
- **反色带**：「关于我」的开场句和 Agent 实验室各是一整条反色带（深色主题里是浅色带，反之亦然），用来分隔章节节奏；颜色变量只写一次，由 `.invert` 复用另一套主题。
- **视觉**：深色墨底、象牙白文字、单一香槟色强调；浅色模式为暖白、墨绿、古铜，选择会被记住。默认深色是有意的设计选择。
- **字体**：英文字标与数字用 Instrument Serif，标签与执行轨迹用 JetBrains Mono，均为站内自带的拉丁子集（共约 46KB，预加载，不依赖 Google Fonts）；中文全部用系统字体，正文 16.5–17.5px。标题与数字标签只在词组之间换行（`keep-all` 配合 `<wbr>` 断点），不会把「数据分析」拆在两行。
- **动效**：只有三种——首屏文字依次出现一次、项目索引悬停（标题右移，类型与时间换成系统链路，行高不变）、案例链路节点在滚入时依次点亮；另有滚动渐显。只有确认在屏幕外的内容才会先隐藏或变暗，观察器失效时内容照常显示；全部遵守「减少动态效果」。没有加载动画、声音或 3D。
- **屏幕适配**：桌面案例为左右两栏，案例标题只在阅读该案例时吸附；1024px 以下改单栏；320px 小屏指标改为竖排。锚点落点只由一处 `--anchor-offset`（顶栏高度 + 16px）控制；跳转目标若还在等待滚动渐显，会先直接显示，落点不受渐显位移影响。
- **无障碍**：两套主题文字对比度均 ≥4.5:1（悬停淡化只在深色主题启用）；单一 banner 地标；首屏字标为 `h1`，朗读顺序为名字 → 主张 → 事实；主题按钮朗读「切换到浅色 / 深色模式」；新标签页链接有读屏提示；跳到正文把焦点放进正文；Windows 高对比度模式下图标与选中状态仍可辨认。
- **稳健性**：每个交互模块独立启动，一个出错不影响其他；残缺的分享链接（如 `#%E0%A4%A`）不会报错；禁用 JavaScript 时隐藏无法使用的按钮并给出说明；复制邮箱在微信等内置浏览器有兜底方案。
- **安全**：CSP 只允许加载本站资源，内联脚本按哈希放行。

## 页面结构

首屏 → 01 项目案例 → 02 关于我 → 03 教育与实习经历 → 04 Agent 实验室 → 05 联系。

- **01 项目案例**：先是大字号索引（编号、名称、类型与时间、关键数字；悬停时类型与时间换成系统链路），再是每个案例一章——系统链路节点图、三个关键数字、问题 / 做法 / 验证、可展开的完整技术细节，评测口径写在案例底部。
- **02 关于我**：反色开场句，然后是自我介绍、经历概览数字、工作方式四步、「合作从提问开始」互动示例、以及「开口前，你可能想问」（毕业时间、方向、项目分工、数字口径——都只写简历里的事实）。
- **03 经历**：时间轴与技术栈台账，末尾可下载完整简历。
- **04 Agent 实验室**：终端风格的本地预设执行轨迹，可选任务与条件（正常 / 无证据 / 工具故障），运行、暂停、继续、单步或重新运行。
- **05 联系**：大号邮箱（可复制）、联系主题预填邮件标题、电话、GitHub 与简历。
- **深链**：`#case-rag`、`#case-research`、`#case-sql` 定位到案例；`#case-rag-detail` 等直接展开细节；`#faq` 定位到常见问题；`#playground` 定位到实验室。章节 id 沿用旧版本（`#approach` = 关于我，`#about` = 经历），以免已分享的链接失效。

## 内容与互动边界

项目和经历依据个人简历整理。研究 Agent 与 Text-to-SQL 为个人项目，内容描述 2026 年 7 月版本。离线演示、真实模型及联网结果分开说明。

Agent 实验室为本地预设演示，不调用模型、数据库或采集用户输入。选择联系主题只预填邮件标题，不自动发送邮件。

网站包含经本人确认可公开的联系方式和完整简历。
