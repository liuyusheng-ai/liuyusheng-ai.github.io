## 当前版本：清楚、整洁、便于阅读

- 主导航收拢为：首页、完整介绍、项目案例、经历、联系。
- 首页明确提供“完整了解我”和“查看项目案例”；完整介绍包含个人方向、能力、合作方式与完整简历下载。
- 三个项目直接展示问题背景、个人实现、结果与验证；无需先打开弹窗即可了解案例。完整技术细节仍可按需展开。
- 正文采用 16–18px 字号，减少装饰标签和重复信息，移除全页动态背景与视差。
- 沟通互动、Agent 实验室与系统设计默认折叠，保持主阅读路径简洁；相关锚点入口可自动展开实验室。
- 首页知识星系保留为次要探索入口，约每 3 秒轮换主题；拖动或选题锁定手动状态，可继续漫游。减少动态效果模式默认暂停。

## 内容与互动边界

项目和经历依据个人简历整理。研究 Agent 与 Text-to-SQL 属于开源示例上的个人二次开发。确定性离线评测、真实模型及联网结果分开说明。

Agent Playground 为本地预设演示，不调用模型、数据库或采集用户输入。选择联系主题只预填邮件标题，不自动发送邮件。搜索功能仅匹配本站个人档案。

网站包含经用户确认可公开的联系方式和完整简历。

此前交互实现参考 Bulletproof 公开前端的滚动分层思想：https://www.wearebulletproof.com/ 。当前版本根据用户最新反馈，以阅读和项目案例为中心简化；页面代码与视觉独立实现。
