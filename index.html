完整技术细节收起技术细节

知识如何进入系统

搭建扫描版养殖书籍加工管线（OCR → 结构适配 → 切片 → 分类 → 入库）。单书试点 65 页产出 146 个切片、132 个有效入库，重复导入 100% 识别跳过。兼容 PDF、Word、Excel、TXT、CSV，按段落累积 500 字切片并保留 50 字重叠。预计算索引随安装包分发，新机首次导入由约 15 分钟缩短至 1 分钟内。

Agent 与业务

基于 ReAct + Skill 路由实现疾病初筛、病例卡、单头牛查询、牛场汇报、财务问答等场景；对接业务平台只读接口，3 万+ 条牛只档案按状态聚合统计；加入同音错字纠正与数字核对护栏，无法在统计结果里找到的数字整句删除。

安全与权限

财务数据按岗位三级授权，金额由程序计算、模型只做解释，全程留审计；构建 19 类套话问法 × 多岗位的攻防题库，任一金额泄露即判失败；回答来源按角色与资料归属实时过滤；财务提问每小时限 30 次，小样本汇总取整防反推单价。

评测与交付

建立 12 套近 400 条 Agentic / Skill 评测集，含 40 条盲测。完成 Docker（PostgreSQL / Redis / Celery / Nginx）部署与 Redis 并发闸门，交付 Windows 桌面安装包及增量自动更新，更新包签名校验，GitHub Actions 自动构建发布。

评测口径：60/60、22/22 与 98.3% 来自真实模型评测集，不等同于线上实际使用效果。

02个人项目 · 2026.07

多角色行业研究与报告生成 Agent

让规划、检索与报告生成衔接起来，并保留每一条证据。

  1. Planner
  2. Researcher
  3. 无来源拦截
  4. Writer
  5. 指标评估
问题
研究任务需要拆解、管理来源；工具失败或资料不足时要明确停下，避免无依据地生成报告。
做法
用 LangGraph 编排 Planner、Researcher、Writer；接入网页搜索、本地 RAG 与 MCP 3 类工具；实现调用预算、超时与重试、无来源停止生成和 SQLite 状态保存。
验证
从任务完成、工具调用成功率、引用覆盖率 3 个维度输出指标；自动化测试覆盖带来源报告、调用预算、无来源拦截、检查点恢复和评测口径。
  • 3协作角色
  • 3类检索工具
  • 6次默认调用预算
  • LangGraph
  • MCP
  • SQLite
  • Tavily
  • Local RAG
完整技术细节收起技术细节

工作流

以 LangGraph 编排 3 个角色，用共享状态传递计划、证据和调用记录，按来源去重后生成带编号引用的报告。网页搜索（Tavily）、本地 RAG 与 MCP 统一输出证据结构，默认离线可运行，规划与写作模型可替换。

可靠性控制

调用预算默认 6 次，支持超时与重试，没有来源时停止生成；逐次记录工具状态、耗时、结果数和异常，单个工具失败不影响其他工具继续检索。SQLite 保存运行状态与证据，已完成任务可按 run_id 恢复。基于官方 MCP Python SDK 实现 stdio 客户端。

评测与测试

从任务完成、工具调用成功率、引用覆盖率 3 个维度输出 Agentic Eval 指标；自动化测试覆盖带来源报告、调用预算、无来源拦截、检查点恢复和评测口径。

项目归属

个人项目，由本人独立开发，使用 Codex 与 Claude 辅助。

验证范围：默认使用离线演示资料，结果不等同于真实联网研究或真实模型质量评测。

03个人项目 · 2026.07

自然语言数据分析 Agent

把业务问题转成受约束的查询语句，再把结果讲清楚。

  1. 问题理解
  2. Schema 检索
  3. SQL 生成
  4. 安全校验
  5. 查询执行
  6. 结果解释
问题
自然语言查询需要对齐数据结构，同时限制危险语句、过量返回和无限修复。
做法
实现 6 节点图，校验失败时经条件路由回到生成节点，修复次数设上限；服务端校验每条 SQL，不把提示词当作唯一防线。
验证
自动化测试覆盖正常分析、危险写操作、多语句注入、行数限制和查询历史记录。
  • 6LangGraph 节点
  • 14类拦截关键字
  • 200单次最多返回行数
  • FastAPI
  • LangGraph
  • SQLAlchemy
  • Plotly
完整技术细节收起技术细节

完整链路

问题理解 → Schema 检索 → SQL 生成 → 安全校验 → 查询执行 → 结果解释。通过 FastAPI、SQLAlchemy 提供查询和历史记录接口，并生成 Plotly 兼容图表配置，支持受限自动修复。

安全边界

服务端校验每条 SQL，仅允许单条 SELECT / WITH，过滤注释后拦截 INSERT、UPDATE、DELETE、DROP、PRAGMA、ATTACH 等 14 类关键字；单次最多返回 200 行，执行超时 3 秒。模型适配层可替换，生成结果都必须通过校验。

工程设计

内置离线演示数据和规则版生成器，无需 API Key 即可运行；默认 SQLite，可通过 DATABASE_URL 接入其他数据库；查询历史保留问题、SQL、行数和执行状态，便于复核。

项目归属

个人项目，由本人独立开发，使用 Codex 与 Claude 辅助。

验证范围：测试基于离线演示数据和规则版生成器，不等同于真实大模型生成 SQL 的端到端表现。
