养殖场知识检索与 Agent

把分散的养殖资料，变成可追溯的查询入口。

解决什么问题

业务资料分散在多种文件里，查询需要保留依据，模型不可用时也需要有明确的降级方式。

我做了什么

整理 15 份资料，构建 67 个知识切片；交付 RAG 接口和工具调用链路，加入参数校验、调用预算与输出护栏。

结果与验证

280 项前后端测试通过；含 live-only 的整体评测为 44/45。

Django / DRF · ChromaDB · ReAct

评测口径：40 条确定性评测与 5 条 live-only 场景分别记录，不将离线结果等同于真实模型能力。

LangGraph · MCP · SQLite

验证范围：离线资料与本地 MCP 验证，不代表真实联网研究或真实模型质量评测。
