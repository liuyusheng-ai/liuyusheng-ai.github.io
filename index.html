完整技术细节收起技术细节

知识如何进入系统

归集并校验鲁西牛预算、饲料营养、疾病防控及养殖制度等 15 份资料，兼容 Excel、Word、PDF、TXT、CSV。完成清洗、去重与 500/50 字符分块，67 个知识切片与 ChromaDB 向量 100% 对齐。

我的实现

使用 Django/DRF、BAAI/bge-small-zh-v1.5、ChromaDB 与 Ollama qwen3.5:4b 交付 6 类知识库 / RAG 接口。以 ReAct 风格 Runner 封装疾病初筛与知识检索，加入 Skill 路由、参数校验、调用预算、循环检测、超时重试与药物剂量输出护栏。

如何验证

45 条养牛场景评测，含 40 条确定性与 5 条 live-only。确定性链路中工具选择、参数提取、任务完成及高风险拦截均为 100%；引用覆盖率 92.9%，无依据回答率 0%，P95 33.48ms。240 项后端测试与 40 项前端测试通过。

工程修复与降级

修复错误路由、批量修改拦截、模型工具参数兼容与非标准 JSON 恢复；Ruff、Django 系统检查与生产构建通过。模型不可用时降级为带来源的资料检索。

评测口径：P95 33.48ms 为确定性链路数据，不代表真实模型推理延迟；含 5 条 live-only 场景的整体结果为 44/45（97.8%）。

多角色行业研究与报告生成 Agent

让规划、检索与报告生成衔接起来，并保留每一条证据。

  2. Researcher
  3. 证据校验

问题
研究任务需要拆解、管理来源；工具失败或中断后，需要明确退出或恢复，避免无依据地生成报告。

验证
11 项自动化测试通过，构建 22 个离线评测场景；6 个 Harness 场景全部通过，本地 stdio MCP 往返验证通过。

  • 11自动化测试通过
  • 22离线评测场景
  • LangGraph
  • MCP
  • SQLite

完整技术细节收起技术细节

工作流

以 LangGraph 编排 Planner、Researcher、Writer，接入离线 Web 源、Local RAG 和可选 MCP 工具。SQLite 保存状态、调用记录、证据与来源，支持按 run_id 恢复。

个人新增

MCP 客户端与本地 stdio 演示服务；工具空结果语义；预算、循环、超时、重试 Harness；断点恢复与可复现评测。无来源时停止生成，未配置 MCP 时不计为成功调用。

验证结果

11 项自动化测试全部通过。22 个离线场景中，15 个研究任务的完成率、引用覆盖率与有效工具结果率均为 100%；6 个 Harness 场景全部通过；基于官方 MCP Python SDK 的本地 stdio 往返验证通过。

完整技术细节收起技术细节

完整链路

问题理解 → Schema 检索 → SQL 生成 → 安全校验 → 只读执行 → 结果解释。通过 FastAPI、SQLAlchemy 和 Plotly 提供查询、历史记录及可视化接口，支持受限自动修复。

安全边界

SELECT 白名单、单语句、超时、最大行数、SQL 长度与修复次数限制；拦截 INSERT、UPDATE、DELETE、DROP、PRAGMA、ATTACH 及危险数据库函数，拒绝空问题并识别危险业务意图。

个人新增

重构 6 节点图和条件路由，新增只读安全校验、危险函数拦截、空问题拒绝、自动修复上限、FastAPI 接口与扩展回归测试。

评测覆盖

50 条离线评测覆盖 25 条正常查询、10 条危险自然语言请求及 15 条对抗 SQL，全部通过。

验证范围：查询链路 P95 8.87ms 来自确定性离线评测，不等同于真实大模型生成 SQL 的端到端表现。
